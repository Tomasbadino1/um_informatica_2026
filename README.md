# Informática 1

Este repositorio está diseñado para lo trabajado durante el año en Informática 1, clases y trabajos prácticos de la materia, organizados por entregas y ejercicios.

## ¿Qué encontrarás aquí?

- `Clases/` - Material de clase organizado por número de clase con ejemplos y ejercicios prácticos.
- `TP1_Badino_Tomas/` - Primer trabajo práctico con ejercicios numerados del 1 al 9.
- `TP2_Badino_Tomas/` - Segundo trabajo práctico con ejercicios numerados del 1 al 7 y ejercicios bonus `B1`, `B2`, `B3`.

Cada archivo `ejercicioX.py` contiene la solución a un ejercicio específico.
