# TP de Informática

Este repositorio está diseñado para alojar trabajos prácticos de informática, organizados por entregas y ejercicios.

## ¿Qué encontrarás aquí?

- `TP1_Badino_Tomas/` - Primer trabajo práctico con ejercicios numerados del 1 al 9.
- `TP2_Badino_Tomas/` - Segundo trabajo práctico con ejercicios numerados del 1 al 7 y ejercicios bonus `B1`, `B2`, `B3`.

Cada archivo `ejercicioX.py` contiene la solución a un ejercicio específico. Este repositorio es ideal para:

- revisar y estudiar soluciones de programación
- preparar entregas de trabajos prácticos
- organizar ejercicios de clase por tema y práctica

## Cómo usar este repositorio

1. Abre la carpeta del trabajo práctico que quieras revisar.
2. Ejecuta los archivos Python con un intérprete compatible.
3. Lee los comentarios o código para entender la lógica de cada ejercicio.

## Consejo

Si estás trabajando en un nuevo ejercicio, puedes usar este repositorio como referencia para mantener un orden claro y consistente en tus entregas.

---

> Nota: este repositorio está pensado como un conjunto de prácticas para apoyar el aprendizaje en la materia de informática.
